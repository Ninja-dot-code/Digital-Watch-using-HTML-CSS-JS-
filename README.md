# Digital Watch

A real-time digital clock built with HTML, CSS, and JavaScript.

---

## About the Project

This project displays the current time and updates every second.  
It is a beginner-friendly practice project focused on working with the `Date` object and `setInterval`.

### Features
- Live digital clock
- Hours, Minutes, Seconds display
- Clean modern styling

---

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
